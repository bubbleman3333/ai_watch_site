### 何が起きた

Claude Code などの[コーディング支援AI](topic:coding)に、PC ゲームの改造データ（MOD）を作らせるための道具一式が GitHub で公開されました。ゲームの仕組みを調べる、中身を解析する、画像生成サービス fal を使って絵・3D・音を作る、ゲーム内で動作を確かめる、紹介動画を録る、という工程ごとに「スキル（作業手順書）」と補助のコマンドが用意されています。Unity や Unreal など 12 種類のゲームエンジン向けの手順を備え、オンラインゲームへの介入やチート対策の回避は断る、手持ちのゲームの 1 人用に限る、という決まりも組み込まれています。

### なぜ大事か

娯楽向けの道具ですが、[AIエージェント](topic:agents)に「調べる→作る→試す→記録する」という長い作業を任せる設計がよくまとまっています。学んだことを次のエージェントのために書き残す仕組みや、外部サービスを [MCP（AIに道具をつなぐ共通の規格）](topic:tools-mcp)で呼ぶ作りは、他の分野にも転用できる考え方です。

### ビジネスでの使いどころ

直接の使いどころは[ソフトウェア](industry:software)・ゲーム開発の会社に限られます。社内向けには、古い業務システムの仕組みを AI に調べさせて改修案を作る作業の手順書を作るとき、この構成（工程ごとに手順書を分け、動作確認と記録まで含める）が参考になります。利用する際はゲームや素材の利用規約を守ることが前提です。
