### 何が起きた

AI コーディングツールが使うモデルを 1 か所で管理するソフト「Magpie」が GitHub で公開され、注目を集めています。Claude Code、Codex、Cursor、Gemini CLI など 30 種類以上のツールに対応し、手元のパソコンで中継役（ゲートウェイ）を動かして、各ツールがそこを通して AI を呼ぶようにします。AI 会社ごとに API キー（利用のための鍵）を登録すると使えるモデルの一覧を自動で取り込み、複数社のモデルをまとめて振り分けたり、負荷を分散したりできます。macOS・Windows・Linux で動き、ライセンスは MIT です。

### なぜ大事か

AI コーディングツールは増え続けていて、それぞれに別のモデル設定や鍵の管理が必要になりがちです。たとえば「ある作業は安いモデル、難しい作業は高性能なモデル」と使い分けたくても、ツールごとに設定し直すのは手間でした。中継役を 1 つ置く方法は、費用の管理や AI 会社の切り替えをしやすくします。

### ビジネスでの使いどころ

[ソフトウェア開発](industry:software)の会社や社内の開発チームで、複数の AI ツールを試している段階なら、モデルの使い分けと費用の見える化に役立ちます。ただし API キーをまとめて預ける仕組みなので、社内で使う場合は鍵の保管方法とアクセス権を決めてから導入してください。関連テーマは[AI によるコーディング](topic:coding)と[オープンモデル](topic:open-models)です。
